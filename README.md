## 钢铁雄心4《星火燎原》制作组专用github仓库

### 概述

> [!TIP]
> 
> - 主要为了同步进度方便制作！
> + 请务必第一时间阅读**[本组GitHub使用规则](#本组GitHub使用规则草案)(草案)**！

### 本组GitHub使用规则(草案)

1. main里只上传实际运行需要的文件，由三组组长或其临时指定**唯一**人选按需上传。所传文件推送前应经过**完整游戏内测试**确认效果无误且不影响其他部分效果。
2. 各组为同步工作进度可按需创建分支用于上传本组**制作中文件**，不要随意修改他人上传的文件，也不要将文件传到其他组的分支里或main里。
3. 有需要将文件传至main供各组制作其他内容参考的较急迫情况的，应@组长/其指定代理人操作，不要私自操作避免不必要的混乱与麻烦。
4. 美工做完的作品注册文件请交由代码组负责上传。作品图片文件上传时名称请美工组长注意参照命名规范，各组制作时也应注释明确命名规范。**但一般情况下建议交由代码组一并上传**(因为实机效果测试需要搭配对应gui可能较占用美工组成员设备空间)。
5. 如有需要请@群主(组长)并附GitHub用户名。
